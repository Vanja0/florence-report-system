# Automated Report Feature

A system-design sample: a scheduled, fan-out, compute-heavy pipeline that
aggregates tabular data and images, does heavy image processing, renders PDFs,
and delivers them securely to subscribers — at scale. Start with [Design.md](Design.md).

Also in this repo: [openapi.yaml](openapi.yaml), [models/data-model.ts](models/data-model.ts), [diagrams/](diagrams/), and the original brief ([Design Exercise (3).pdf](Design%20Exercise%20(3).pdf)).
